# directives

SOPs/runbooks — what to do, not how the code does it (CLAUDE.md → Architecture & System Layers, Layer 1).

## Belongs here

- One directive per feature/exercise: goal, inputs, outputs, edge cases, safety constraints, verification expectations
- Human-readable, living documents

## Never goes here

- Business logic or code
- Anything that can be tested via code instead of validated narratively
